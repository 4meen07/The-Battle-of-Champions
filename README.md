# The-Battle-of-Champions

**The Battle of Champions** is a browser-based 2D fighting game built using **HTML, CSS and JavaScript**. The game features interactive combat, an AI-controlled opponent with multiple difficulty levels, stamina and health systems, defensive mechanics, animations, sound effects and local two-player gameplay.

## 🎮 Features

* 🤖 **AI Opponent** – Fight against an AI-controlled opponent with Easy, Medium and Hard difficulty levels.
* 👥 **2-Player Mode** – Play locally against another player using separate controls.
* 👊 **Combat System** – Perform head jabs and body jabs with different damage, range and stamina costs.
* 🛡️ **Defensive Mechanics** – Block, duck and dodge incoming attacks.
* ❤️ **Health & Stamina** – Manage health and stamina throughout each fight.
* ⏱️ **90-Second Rounds** – Win by knockout or have more health when the timer reaches zero.
* 💥 **Combat Effects** – Includes hit effects, screen shake, animations and visual feedback.
* 🔊 **Sound Effects & Music** – Audio feedback for attacks, impacts, countdowns and victories.
* 🏆 **Victory System** – Determines winners, draws and knockouts based on the game's rules.

## 🤖 AI System

The AI opponent uses rule-based decision-making to respond to the player's actions and the current game state. Its behaviour changes depending on the selected difficulty, including its reaction speed, movement, attacking frequency and defensive decisions.

The AI can move towards the player, attack, block, duck and dodge, creating different gameplay behaviour across the three difficulty levels.

## 🛠️ Technologies Used

* **HTML5** – Game structure and canvas
* **CSS3** – User interface and visual styling
* **JavaScript** – Game logic, controls, combat system, AI behaviour, animations and audio
* **HTML Canvas API** – Real-time game rendering
* **Web Audio API** – Sound effects and music

## 🚀 How to Play

1. Download or clone the repository.
2. Open the HTML file in a modern web browser.
3. Select a game mode and difficulty.
4. Enter your fighter name.
5. Use the controls to fight your opponent.
6. Reduce your opponent's health to zero or finish the round with more health.

## 📌 Project Purpose

This project was developed to practise **JavaScript programming, game development, user interaction, algorithmic decision-making and AI behaviour** while creating a complete playable browser-based game.
